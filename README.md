## Flagship Research Project — Solo Lead

### 🧠 Multi-Task Brain Tumor Diagnosis on BraTS20

*The project that demonstrates research-grade AI + end-to-end production engineering in one codebase.*

**Role:** Lead AI Researcher & Full-Stack Engineer &nbsp;·&nbsp; `Solo`

**Dataset:** BraTS 2020 — Multi-modal 3D MRI (T1, T1ce, T2, FLAIR)

**Architecture:** Dual-Head U-Net with shared encoder backbone
- **Kendall Uncertainty Weighting** — adaptive multi-task loss balancing
- **PCGrad Gradient Surgery** — conflict-free multi-objective training
- **FastAPI** backend + **React + Tailwind CSS** frontend
- **Docker** containerization · **W&B** experiment tracking
- **Render** (backend) + **Vercel** (frontend) production deployment

| Metric | Result |
|--------|--------|
| Dice Score | **0.726** |
| ROC-AUC | **0.962** |
| Inference Latency | **5.3 ms/slice** |
| Latency Reduction | **−41%** |
| Parameters | **7.77M** (vs 15.5M baseline) |
| Parameter Saving | **50%** |
| Tasks | Segmentation + Classification |
